# Security Policy

## Reporting Security Issues

The Kuasar maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kuasar-io/kuasar/security/advisories/new) form.

For more details, see the [Kuasar security policy](https://github.com/kuasar-io/kuasar/blob/main/SECURITY.md).
